# Helix Studio — Product Vision

**helixstudio.org**

## Overview

Helix Studio is an AI-powered software engineering platform — a full coding environment in the class of Cursor, Windsurf, and Claude Code. It pairs a real editor with a repository-aware AI assistant and a multi-agent review pipeline so individuals and teams can plan, build, review, and ship software from one place.

## What users can do

- **Chat with a repository-aware AI** that understands the whole codebase, not just the open file.
- **Generate production code** with a plan-first workflow and inline, reviewable diffs.
- **Edit files safely** in a real editor with tabs, an expandable file tree, and syntax highlighting.
- **Analyze any repository** — purpose, architecture, dependencies, data flow, and risk findings.
- **Run a multi-agent pipeline** — Architect → Engineer → Reviewer → Security → Performance — that confirms before it acts.
- **Browse and toggle skills** — 24 bundled software-engineering skills, loaded on demand.
- **Deploy and monitor** — environments, build logs, and deployment history.
- **Customize the workspace** — light/dark theme, accent color, density, and editor font size, all persisted.

## Core features

### AI chat
Repository-aware, plan-first, with inline diffs and confirm-before-action.

### Code generation
Production-grade, typed, tested, with error/loading/empty states.

### File editing
Real editor: tabs, tree, diff view, dirty-state indicators.

### Multi-agent system
Architect · Engineer · Reviewer · Security Auditor · Performance Engineer.

### Repository intelligence
Indexing, embeddings, semantic search, static analysis.

### Skills
A library of opinionated engineering skills the agent invokes when relevant.

### Memory
Project decisions and conventions remembered across sessions.

### Deployments
One-click deploy, build logs, environment status, rollback history.
