Helix v3 — Plan Mode, Activity, Gradebook, Board

Four additions: one in the editor's AI chat, three in Spaces. Everything works with the accounts, Spaces, and editor you already have.
🗺️Plan mode in the AI chatEDITOR

A Plan/Build switch next to the chat box. In Plan, the agent only reads your project and replies with a numbered implementation plan — what changes, in which files, and why. Nothing is written until you press Approve & build; Revise lets you adjust the plan first. Useful before bigger changes.

How it worksA plan turn runs the same agent with its tool list cut to read-only (list_files, read_file, search_files) and a planning prompt; write tools are also blocked server-side. Approving sends the plan text back as a normal build turn.
📰Space activity feedSPACES

Every Space now shows what happened recently: who joined or left, which projects were shared or pushed to git, assignments posted and submitted, tasks added and completed. Opens automatically on the Space page; quiet until there's something to show.

How it worksRoutes record one event row after each action (never failing the action itself); GET /api/spaces/[id]/activity returns the latest 50 to members only. Grades are never shown in the feed.
🧮Classroom gradebookCLASSROOMS

One grid with every student and every assignment: not started, in progress, submitted, or the grade once reviewed — plus a per-student completion count. Column headers jump to the assignment's grading page. Visible to the instructor only.

How it worksGET /api/spaces/[id]/gradebook composes assignments × members × submissions in three queries and returns a cell map keyed assignmentId:userId.
📋Task boardSPACES

A three-column board (to do / in progress / done) in every Space. Any member can add tasks, drag them between columns (or use the arrow buttons — keyboard friendly), and assign them to a member. Deleting is limited to the task's creator or the Space owner.

How it worksA SpaceTask row per card; moves are a single PATCH whether dragged or clicked. Completions land in the activity feed.
