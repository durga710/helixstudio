# Helix Studio Circuit Core

Selected logo direction packaged as practical SVG files.

## Files

- `circuit-core-full.svg` - main full logo lockup.
- `circuit-core-mark.svg` - square icon/avatar mark.
- `circuit-core-wordmark.svg` - wordmark-only lockup.
- `circuit-core-monochrome.svg` - one-color version for print or restricted-color use.
- `circuit-core-favicon.svg` - simplified 64 x 64 favicon SVG.
- `circuit-core-preview.html` - local preview/download page.

## Palette

- Core black: `#070b12`
- Panel black: `#0d1626`
- Circuit cyan: `#00ffd1`
- Electric blue: `#3b82f6`
- Violet edge: `#c084fc`
- Text white: `#f8fbff`
